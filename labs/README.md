# Labs · BDY1101-005D

Laboratorios prácticos de **Base de Datos Aplicada I**.

## Propósito

Los labs deben convertir cada concepto relevante en una práctica reproducible, verificable y claramente relacionada con los resultados de aprendizaje.

```text
concepto
→ ejemplo guiado
→ práctica
→ evidencia
→ verificación
→ transferencia a evaluación cuando corresponda
```

## Cobertura esperada por experiencia

### EA1 · Modelamiento conceptual

Labs y prácticas sobre:

- reconocimiento de información y entidades;
- entidades fuertes y débiles;
- atributos obligatorios y opcionales;
- identificadores únicos;
- relaciones y cardinalidades;
- modelo conceptual extendido.

### EA2 · Normalización y modelo relacional

Labs y prácticas sobre:

- identificación de redundancia;
- normalización;
- transformación hacia modelo relacional;
- claves primarias y foráneas;
- introducción práctica a Oracle APEX cuando corresponda.

### EA3 · SQL y APEX

Labs y prácticas sobre:

- DDL y creación de tablas;
- constraints;
- secuencias e inserción de datos;
- consultas `SELECT`;
- alias, operaciones matemáticas y ordenamiento;
- filtros y operadores;
- construcción de dashboards en Oracle APEX.

## Contrato mínimo de un lab

Cada laboratorio deberá indicar:

1. objetivo;
2. RA/IL asociado;
3. prerrequisitos;
4. contexto o caso;
5. instrucciones paso a paso;
6. scripts, modelos o artefactos necesarios;
7. resultado esperado;
8. criterios de verificación;
9. evidencia que debe conservar el estudiante;
10. troubleshooting cuando aplique.

## Relación con semanas

Los labs se enlazarán desde la semana académica correspondiente **una vez recibido el cronograma oficial**. Hasta entonces se pueden crear por experiencia/actividad sin inventar una asignación temporal.

Los recursos institucionales originales permanecen en Drive/AVA; el repo publica prácticas docentes, ejemplos y material derivado adecuado para consumo directo por estudiantes.
